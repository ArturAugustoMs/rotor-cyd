Controlador de rotor para CYD

Conecte a placa, escolha a porta serial e confirme. O instalador aplica o bootloader, a tabela de partições e o firmware de uma vez.

Este navegador não suporta Web Serial. Use Google Chrome ou Microsoft Edge. A gravação exige HTTPS. Abra esta página pelo link do GitHub Pages.

Compatível com Chrome, Edge e Chrome para Android. Após a gravação, o CYD abre o AP Rotor-Setup para configurar o Wi-Fi.
